\begin{itemize}[noitemsep,topsep=1.5pt,leftmargin=*]

\section*{4. Methodology}

\subsection*{Stage 1: Web Scraping Layer}
\noindent\textbf{Automated Daily Ingestion:} Every morning at 08:00 AM, Apache Airflow orchestrates daily automated data extraction across 11 key retail and service sectors in Cambodia.\\[0.1cm]
\noindent\textbf{Protocols \& Methods:}
\begin{itemize}[noitemsep,topsep=1pt,leftmargin=*]
    \item \textbf{Direct Store APIs (REST \& GraphQL):} Directly targets internal reverse-proxy endpoints (AEON 1, AEON 3, DeliShop Asia, BookMeBus) and GraphQL queries (L192) to download structured JSON product catalogs, bypassing client-side web rendering.
    \item \textbf{TLS Fingerprinting (\texttt{curl\_cffi}):} Executes HTTP requests with Chrome TLS/JA3 fingerprint impersonation to bypass Cloudflare anti-bot defenses and Web Application Firewalls (WAF) with polite throttling (0.5s--1.0s delay).
    \item \textbf{Dynamic Browser Escalation (Headless Playwright):} Automatically launches an asynchronous headless Chromium browser context when encountering Cloudflare challenges or HTTP 403 Forbidden barriers (e.g., AEON) to render dynamic JavaScript and extract live prices.
    \item \textbf{Public Web Feeds \& HTML Parsing:} Uses BeautifulSoup to extract housing rentals (Khmer24, Realestate.com.kh), scrapes official fuel price caps via Tela Khmer Telegram web feeds with Khmer numeral translation (Khmer digits $\rightarrow$ 0--9), and fetches daily official MEF USD/KHR exchange rates.
    \item \textbf{Defensive Quality Controls:} Enforces a zero-record circuit breaker (raises an error on empty scrapes to prevent data wipeout) and maintains a static fallback matrix if third-party websites undergo outages.
\end{itemize}

\subsection*{Stage 2: Bronze Layer (Raw Lake Ingestion)}
\noindent\textbf{Database Table:} \texttt{bronze.raw\_prices}
\begin{itemize}[noitemsep,topsep=1pt,leftmargin=*]
    \item \textbf{What it does:} Acts as an immutable, append-only raw data repository preserving the exact raw data as fetched from the web.
    \item \textbf{Stored Fields:} \texttt{store\_id}, \texttt{source\_name}, \texttt{item\_description\_raw}, \texttt{price}, \texttt{currency}, \texttt{source\_url}, \texttt{scraped\_at}, \texttt{batch\_id}.
\end{itemize}

\subsection*{Stage 3: Silver Layer (Standardization, AI Classification \& Quality Control)}
\noindent\textbf{Database Table:} \texttt{silver.standardized\_prices}\\[0.05cm]
The Silver Layer has 3 main jobs:
\begin{center}
    \textbf{[Raw Scrape] $\longrightarrow$ 1. Clean Data $\longrightarrow$ 2. Match Product $\longrightarrow$ 3. Classify Basket $\longrightarrow$ [Clean Silver Item]}
\end{center}

\vspace{-0.15cm}
\subsubsection*{1. Clean the Data (Standardize)}
\begin{itemize}[noitemsep,topsep=1pt,leftmargin=*]
    \item \textbf{Removes noise:} Deletes marketing words (SALE, HOT DEAL, 50\% OFF) and old price tags.
    \item \textbf{Normalizes units:} Converts volumes and weights into standard sizes (500ml, 1kg) to calculate price per liter/kg.
    \item \textbf{Handles dual currency:} Converts USD and Khmer Riel using the daily MEF exchange rate.
    \item \textbf{Fixes Khmer text:} Segments unspaced Khmer words and translates digits (Khmer digits $\rightarrow$ 0--9).
\end{itemize}

\subsubsection*{2. Match the Product (Find the Same Item)}
\noindent
Connects identical products across different stores (e.g., AEON vs. DeliShop) using a 5-step waterfall:
\begin{itemize}[noitemsep,topsep=1pt,leftmargin=*]
    \item \textbf{Barcode (GTIN):} Exact match.
    \item \textbf{Store SKU:} Match with past days' catalog.
    \item \textbf{Clean Name \& Size:} Exact text match with size protection (prevents 330ml matching 1.5L).
    \item \textbf{AI Vector (pgvector):} Matches English and Khmer equivalents ($\ge 95\%$ similarity).
    \item \textbf{Fuzzy Spelling:} Catches small typos.
\end{itemize}

\subsubsection*{3. Classify into Official Baskets (UN COICOP)}
\begin{itemize}[noitemsep,topsep=1pt,leftmargin=*]
    \item Uses Google Gemini AI in batches to assign the official 4-digit government code (e.g., \texttt{01.1.1} for Rice/Bread).
    \item \textbf{Strict Guardrails prevent AI mistakes:}
    \begin{itemize}[noitemsep]
        \item Pet Food $\rightarrow$ Goes to Pets (\texttt{09.3.1}), never human food.
        \item Shampoo / Soap $\rightarrow$ Goes to Personal Care (\texttt{12.1.3}), never food.
        \item Beer / Wine $\rightarrow$ Goes to Alcohol (\texttt{02.1}), isolated from soft drinks.
    \end{itemize}
\end{itemize}

\vspace{-0.10cm}
\subsection*{The Gold Layer in Brief: From Clean Products to Official CPI}
\noindent
The Gold Layer applies official international standards (ILO / UN guidelines) to turn thousands of clean daily prices into national economic indicators in 3 main steps:
\begin{center}
    \textbf{[Clean Silver Items] $\longrightarrow$ 1. Jevons Index $\longrightarrow$ 2. Laspeyres Aggregation $\longrightarrow$ 3. Core CPI \& Marts}
\end{center}

\vspace{-0.15cm}
\subsubsection*{1. Elementary Index Calculation (Jevons Formula)}
\begin{itemize}[noitemsep,topsep=1pt,leftmargin=*]
    \item \textbf{Jevons Geometric Mean:} Instead of a simple average (which gets distorted by expensive luxury items), the system uses the geometric mean:
    \begin{equation*}
        I_{\text{rice}, t} = \left( \frac{P_{1,t}}{P_{1,0}} \times \frac{P_{2,t}}{P_{2,0}} \times \cdots \times \frac{P_{n,t}}{P_{n,0}} \right)^{\frac{1}{n}}
    \end{equation*}
    \item \textbf{Missing Price Imputation:} If an item is temporarily out-of-stock, a 7-day carry-forward rule fills in the price so the index doesn't jump wildly.
\end{itemize}

\subsubsection*{2. Official National Aggregation (Laspeyres Formula)}
\noindent
Cambodians spend more money on food than on furniture. To reflect real life, the 12 COICOP divisions are combined using official government survey expenditure weights (CSES 2020):
\begin{equation*}
    \text{Headline CPI} = \sum \Big( \text{Weight} \times \text{Division Index} \Big)
\end{equation*}
\begin{itemize}[noitemsep,topsep=1pt,leftmargin=*]
    \item \textbf{Food \& Drinks (01):} 44.775\% (Highest weight in Cambodia)
    \item \textbf{Housing \& Electricity (04):} 17.062\%
    \item \textbf{Transport \& Fuel (07):} 12.203\%
    \item \textbf{All other 9 Divisions:} Remaining 25.960\% (Clothing, Health, Telecom, etc.)
\end{itemize}

\subsubsection*{3. Central Bank Metric: Core CPI}
\noindent
For central bankers at the National Bank of Cambodia (NBC), temporary global oil spikes or seasonal vegetable floods distort the real picture.
\begin{itemize}[noitemsep,topsep=1pt,leftmargin=*]
    \item \textbf{Refined Core CPI:} The system calculates a second official index that removes Food (\texttt{01}) and Energy (\texttt{04}):
    \begin{equation*}
        \text{Core CPI} = \frac{\sum_{\text{ex-Food, ex-Energy}} w_j \cdot I_j}{\sum w_j}
    \end{equation*}
    This shows the underlying, long-term price stability of the economy.
\end{itemize}

\subsection*{Stage 4: Nowcasting}
\begin{itemize}[noitemsep,topsep=1pt,leftmargin=*]
    \item \textbf{Methodology (Two-Tier Hybrid Approach):} Rather than using a black-box AI model, we use a hybrid economic approach:
    \begin{itemize}[noitemsep]
        \item \textit{Tier 1 (Official Aggregation):} We use fixed CSES expenditure weights across all 12 COICOP divisions following official NIS/ILO Laspeyres standards. We calculate both Headline CPI and Core CPI (excluding volatile food and energy).
        \item \textit{Tier 2 (Forward Econometric Projection):} For past observed days, we compute the realized daily average from scraped prices. For the unobserved remaining days of the month, we nowcast daily drift rates using regularized Ridge Regression (\texttt{RidgeCV}) with Bayesian prior shrinkage.
        \item \textit{Blending:} We combine realized days and projected days using a time-weighted formula that smoothly converges onto actual data as the month ends.
    \end{itemize}
    \item \textbf{Cambodia-Specific Market Features:}
    \begin{itemize}[noitemsep]
        \item \textit{5 Core Baskets:} We model the 5 high-velocity categories ($\sim$81.6\% of Cambodia's basket): Food (44.8\%), Housing/Utilities (17.1\%), Transport (12.2\%), Restaurants (3.1\%), and Alcohol (1.6\%).
        \item \textit{Freight Spillover:} Fuel price momentum (Transport) is selectively fed into Food and Restaurant catering to model logistics cost pass-through.
        \item \textit{Holiday Handling:} We built an exponential decay kernel for Khmer holidays (Khmer New Year, Pchum Ben, Water Festival) so temporary ceremonial spikes are not misread as permanent inflation.
        \item \textit{FX Pass-Through:} Ingests daily USD/KHR commercial exchange rates.
    \end{itemize}
\end{itemize}
